# 📰 MeMarathi AI

MeMarathi AI is an AI-powered Marathi News Classification system built using Natural Language Processing (NLP) and Machine Learning. The application classifies Marathi news articles into categories such as Politics, Sports, Crime, Health, Education, Technology, Entertainment, Travel, Fashion, Auto, Bhakti, and International News.

The project uses TF-IDF feature extraction with a Linear Support Vector Machine (LinearSVC) classifier trained on the LDC Marathi News Dataset. A FastAPI backend provides prediction APIs, while a responsive web interface allows users to classify Marathi news articles instantly.
